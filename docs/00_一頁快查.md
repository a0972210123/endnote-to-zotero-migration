### 🔴 三大鐵則

1. **用 XML 匯出，不要用 RIS** — RIS 不帶 PDF、不帶分組
2. **XML 必須存進 `<library>.Data` 資料夾內** — 存錯位置：書目都在，**PDF 全部不見**
3. **匯入前關掉 auto-sync**，大庫分批（每批 500–1000 筆）
